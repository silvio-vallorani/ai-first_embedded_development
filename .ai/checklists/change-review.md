# Change review checklist

- [ ] Target (board/core/configuration) is explicit.
- [ ] MCU/board/application boundaries are preserved.
- [ ] Paired-release invariants are preserved.
- [ ] Host unit tests and relevant mocks are updated.
- [ ] Hardware-dependent assumptions are labelled.
- [ ] Documentation and ADRs match the implementation.
- [ ] No secrets, signing keys or generated credentials are committed.
